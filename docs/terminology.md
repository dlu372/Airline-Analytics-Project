# Terminology and claim boundaries

## Primary analysis unit

The primary unit is **a directed airline–origin–destination route presence** in
the OpenFlights June 2014 historical snapshot. A route from A to B is distinct
from a route from B to A.

The primary network excludes rows marked as codeshare and is described as a
**non-codeshare operating-network proxy**. It is not a verified record of the
operating carrier. The all-listed network is retained only for sensitivity
analysis.

## Allowed language

- directed route presence
- listed carrier
- network breadth
- airport connectivity
- geographic reach
- hub dependence
- reciprocal connectivity
- single-listed-carrier route
- historical network snapshot

## Prohibited language without a new supporting data source

Do not describe route-presence counts as:

- frequency
- departures
- arrivals
- passenger demand
- market share
- monopoly
- profitability
- busiest

The dataset also does not measure flight schedules, seat capacity, passenger
traffic, revenue, cost, profitability, or current market activity.
